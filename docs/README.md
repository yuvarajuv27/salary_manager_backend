# Salary Manager docs (Backend)

**Whole-project requirements** are canonical in the frontend repo. This backend stores BE-specific feature requirements, architecture, and plans.

## Layout

| Path | Purpose |
|---|---|
| [requirements/README.md](./requirements/README.md) | Link to whole-project requirements + BE features |
| [requirements/features/](./requirements/features/) | BE-owned feature requirements |
| [architecture/](./architecture/) | Architecture notes per feature |
| [plans/](./plans/) | Implementation plans per feature |

Sibling frontend: `../salary_manager_frontend_local`.

## Superpowers plugin

Install **Superpowers** at **project** scope only (Customize → Superpowers → Install → Project). Do not install at user/global scope.
