# Install Superpowers (project scope only)

Same steps as the frontend guide. Install at **project** scope in this backend workspace as well.

1. Focus `salary_manager_backend` in Cursor.
2. Customize → search **Superpowers**, or `/add-plugin superpowers`.
3. Install → **Project** (not User / Global).
4. Quit and reopen Cursor if skills do not load.
5. Confirm `/brainstorming` (or equivalent) is available.

See also: `../salary_manager_frontend/docs/SUPERPOWERS_INSTALL.md`.
